# Oasis Infobyte Web Development Internship - Task 1
## ApexPulse Modern Responsive Landing Page

A modern, high-converting SaaS landing page built with semantic **HTML5**, **CSS3 (Custom Properties & Glassmorphism)**, and **Vanilla JavaScript ES6+**.

---

### 🌟 Live Preview & Design Highlights
- **Ultra-Modern Cyber Dark Theme**: Deep obsidian surfaces, neon accents (indigo, cyan, emerald), and ambient radial glows.
- **Glassmorphism & Depth**: Translucent cards with backdrop filters and interactive 3D tilt effects.
- **Fluid Responsiveness**: Custom media queries engineered for optimal view across desktop displays, tablets, and smartphones.
- **Zero Heavy Dependencies**: Clean, vanilla code using Google Fonts (*Outfit* and *Plus Jakarta Sans*) and FontAwesome 6 icons.

---

### 🚀 Key Features

1. **Sticky Glassmorphic Header & Navigation**:
   - Dynamic blur and shadow on scroll.
   - Interactive mobile hamburger menu with smooth drop-down transitions.
   - Live scroll-spy highlighting active sections.

2. **Hero Section**:
   - Dynamic release badge with pulse indicator.
   - High-converting CTA buttons (*"Start 14-Day Free Trial"* and interactive *"Watch Demo"* modal).
   - Animated statistics counter (Uptime SLA, deployments, and velocity).
   - Interactive 3D tilt dashboard card featuring live cluster metrics, traffic bar charts, and terminal emulation.

3. **Infinite Marquee Partner Ticker**:
   - Seamless loop featuring engineering partners (AWS, Docker, GitHub, Google Cloud, Cloudflare, Linux).

4. **About Us Section**:
   - 3-column feature grid displaying Mission, Intelligent Telemetry, and Zero-Trust Security metrics.

5. **Services / Features Showcase**:
   - 6 interactive feature cards with hover glowing borders and icon transitions.

6. **Interactive Pricing Switcher**:
   - Smooth toggle switch between **Monthly** and **Annual** billing with automatic 20% discount calculation.

7. **Testimonial Reviews**:
   - Customer quotes, 5-star ratings, reviewer avatars, and executive titles.

8. **Expandable FAQ Accordion**:
   - Smooth accordion collapse/expand behavior with active state indicators.

9. **Interactive Contact Form**:
   - Full client-side input validation (name length, regex email format, message length).
   - Dynamic button spinner and animated toast notification on successful submission.

10. **Back to Top Floating Button**:
    - Automatically displays after 400px of scrolling for effortless one-click return to top.

### 🛠️ Technologies Used
- **HTML5**: Semantic tags (`<header>`, `<main>`, `<section>`, `<article>`, `<footer>`).
- **CSS3**: CSS Grid, Flexbox, Custom Properties (`--vars`), Keyframe Animations, Glassmorphism (`backdrop-filter`).
- **JavaScript**: ES6+, `IntersectionObserver`, DOM event handling, Regex validation, RequestAnimationFrame.
- **Typography & Icons**: Google Fonts (`Outfit`, `Plus Jakarta Sans`) & Font Awesome 6.

---

### 💻 How to Run
1. Navigate into `OIBSIP_TASK_1_Landing_Page`.
2. Double-click `index.html` or open it with any modern web browser (Google Chrome, Firefox, Microsoft Edge, Safari).
3. Alternatively, launch a local web server (e.g. VS Code Live Server or `python -m http.server 8000`).
